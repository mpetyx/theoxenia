# EXP-010 Project Blue Book OCR

`make disclosure-ocr` runs Tesseract on a one-page generated PDF:

```bash
xenia disclosure ocr tests/fixtures/disclosure/known-answer.pdf
```

The case-file command is the same, with the PDF kept under `data/` and not committed:

```bash
xenia disclosure ocr data/bluebook/ProjectBlueBook-Ramstein-03-26-1962.pdf \
  --source-url https://documents2.theblackvault.com/documents/projectbluebook/ProjectBlueBook-Ramstein-03-26-1962.pdf \
  --hand-lines tests/fixtures/disclosure/ramstein-page1-lines.json
```

`xenia disclosure prompt` prints the IncidentTelemetry schema and an instruction to leave unknown fields null. `xenia disclosure validate` checks one `ocr.json` against that model. Neither command calls a model.

`xenia disclosure count` reads finished EXP-010 OCR manifests and writes a later manifest whose `pages_processed` is the sum of those recorded counts. It does not OCR again.

## What is measured

PyMuPDF renders each page at 2x. OpenCV converts that render to grayscale. Tesseract reads the grayscale PNG with `--psm 6`. The manifest records `pages_processed`, the Tesseract version line, and the SHA-256 of the PDF. The PDF itself stays out of Git.

A full-page character error rate is the Levenshtein distance divided by the length of a hand-checked reference. It is recorded only for pages that have a reference. A page without a reference does not get a rate.

A hand line is a rectangle on that same 2x render. The reference text was typed from the crop before Tesseract ran on it. The rate uses Tesseract's stdout for that crop, including any trailing newline, divided into the Levenshtein distance by `len(reference)`. Text outside the rectangle is not part of the rate. Handwriting that was not read is not given a rate.

`case_date` and `location` stay null. They are not copied out of the OCR text.

## Page card

This branch does not contain the Mission Control renderer that lights the Blue Book card. That renderer is on the detail-pages branch. It reads a non-demo manifest whose `experiment_id` is `EXP-010` and whose parameters include integer `pages_processed`. After that branch is merged with this one, that integer is what the card prints.
